# 台灣經濟指標

以季度為主軸的台灣經濟指標儀表板，用來評估景氣位置、產業狀況與投資環境。資料每月自動更新，網站部署在 GitHub Pages。

## 網站內容

| 頁面 | 內容 |
|---|---|
| 總覽 | 景氣燈號、景氣摘要、12 項關鍵指標、景氣循環時鐘、燈號分數走勢 |
| 景氣／產業／半導體／房地產／物價／金融／勞動／股市 | 各分類的指標卡片（2000 年以來季資料，標示景氣收縮期）；產業頁另有外銷訂單與工業生產的年增率比較 |
| 指標詳細頁 | 季／月切換、5 年／10 年／全部、年增率與原始數值圖、資料表、CSV 下載 |
| 季度快照 | 任選一季，列出所有指標的當季值、上季、去年同季與歷史分位 |

## 資料來源

| 來源 | 取得方式 | 指標 |
|---|---|---|
| 行政院主計總處 總體統計資料庫 | SDMX JSON API | GDP 與貢獻度、景氣指標、工業生產、外銷訂單、進出口、零售餐飲、物價、貨幣、利率、匯率、勞動、股市、建照、房貸 |
| 國家發展委員會 | 開放資料 CSV | 製造業 PMI、非製造業 NMI、景氣循環峰谷日期 |
| 中央銀行 | 開放資料 CSV | 10 年期公債次級市場殖利率 |
| 臺灣證券交易所 | 每日收盤行情 | 半導體類股指數（月底收盤） |

目前無法自動取得（來源網站封鎖境外連線）：經濟部統計處細業資料、財政部關務署 HS 貿易資料、內政部住宅價格指數、公開資訊觀測站月營收。

## 專案結構

```
pipeline/
  indicators.py   指標定義（新增或調整指標只要改這裡）
  sources.py      各資料來源的抓取函式
  fetch.py        抓取所有指標 → data/raw/
  build.py        月轉季、年增率 → site/data/data.json
data/raw/         原始序列（納入版本控制，可追蹤資料修正）
site/             靜態網站（HTML + JavaScript + ECharts）
.github/workflows/update.yml   每月自動更新與部署
```

只使用 Python 標準函式庫，不需要安裝套件。

## 本機執行

```bash
python -m pipeline.fetch          # 抓取全部指標（也可只抓指定 id：python -m pipeline.fetch cpi pmi）
python -m pipeline.build          # 產生 site/data/data.json
cd site && python -m http.server  # 開啟 http://localhost:8000
```

## 資料處理規則

- **月轉季**：只計算三個月都到齊的季度。比率與指數取平均、流量（訂單、出口、建照）加總、存量與股價取季末值。
- **年增率**：與去年同期相比。本身就是比率的指標（經濟成長率、失業率、PMI、利率、本益比）不計算年增率。
- **歷史分位**：最新一季在 2000 年以來所有季度中的相對位置。
- **景氣收縮期**：依國發會公布的高峰到谷底；尚未認定谷底的循環不畫陰影。
- **異常保護**：單一來源失敗時保留上次資料，網站會標示更新失敗的指標；新資料筆數驟減時視為異常，不覆蓋舊資料。
